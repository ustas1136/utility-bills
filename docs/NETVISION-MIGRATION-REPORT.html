Три темы

Один и тот же дашборд: светлая, «комфорт» и тёмная. Переключение — атрибутом data-theme, значения из палитр стандарта.

Что не взяли

  • Синий акцент стандарта — решение проекта: действие осталось emerald (oklch(0.55 0.17 160)), из стандарта взята роль токена, а не значение.
  • Хеш-манифест tokens.json — не нужен: стандарт лежит локально в docs/Netvision_Design_Standard/ и исключён из репозитория через .gitignore.
  • --control — отдельный цвет рамки панелей не заводили: панели используют --border.
  • Компоненты AlertDialog и Sheet — удалены как неиспользуемые; Popover оставлен про запас.

Откат

Точка до миграции помечена тегом pre-netvision-migration (коммит 9a33f13, «docs: fill design system, add ub dev control script») и запушена в origin — откат доступен всем, у кого есть репозиторий.

# Откат к состоянию до миграции
git switch --detach pre-netvision-migration   # посмотреть
git revert --no-commit pre-netvision-migration..HEAD && \
  git commit -m "revert: Netvision migration"

# Или полный сброс (осторожно — потеряет новые коммиты)
git reset --hard pre-netvision-migration
Про git reset --hard: он стирает коммиты после тега, и вернуть их из истории уже не получится — только из origin/main (git reset --hard origin/main) или через git reflog. git revert безопаснее: он добавляет обратный коммит и сохраняет всю историю миграции. Архивировать состояние можно в любой момент: git archive pre-netvision-migration | gzip > backup.tar.gz.

Что дальше

Известные долги

  • text-white в destructive-вариантах ui/button.tsx и ui/badge.tsx — белым по светлому --destructive в тёмной теме; контраст под вопросом.
  • Пункты меню и селектов подсвечиваются фоном (focus:bg-accent) — фокус-обводка 2/3 px применена к контролам, но не к пунктам списков.
  • Категорийные цвета QuickActions и типов объектов не следуют comfort-теме: у них нет токенов для четырёх различимых оттенков.

Roadmap

  • Привести контраст destructive-вариантов к §7 и убрать text-white.
  • Решить судьбу --control: ввести токен рамки панелей или зафиксировать --border как осознанный выбор.
  • Расширить фокус-обводку на пункты списков и проверить обход клавиатурой целиком.
  • Прогонять 9 скриптов визуальной проверки в CI, а не вручную.
  • Держать docs/DESIGN.md в синхроне: он уже один раз отстал на восемь шагов.
